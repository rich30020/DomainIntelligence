# Domain Intelligence

Applicazione desktop per Domain Enumeration,
Brand Protection e Threat Intelligence.

## Tecnologie

- Python
- PySide6
- SQLite
- HTTPX
- BeautifulSoup
- Playwright

## Avvio

Attivare l'ambiente virtuale:

.\.venv\Scripts\Activate.ps1

Avviare l'applicazione:

python main.py
